# Roadmap

No completion dates or operational claims for planned features.

1. Stabilize the local core and improve portable CLI errors.
2. Generic configurable agent roles and a richer offline desktop workflow.
3. Provider adapter protocol with an offline mock and cancellation tests.
4. CostGuard persistent reservations and EconomyMode with concurrency/failure tests.
5. SmartTeam and cost-aware routing with explicit evidence for model availability and price freshness.
6. Tool permissions, sandbox boundaries and streaming conversation UI.

Good first contributions: explain CLI validation errors without tracebacks; test Unicode paths on Linux and Windows; improve desktop keyboard navigation; add documented configurable role labels without cloud calls. Each requires tests and documentation. Do not add private deployments or content.
