# Contributing

Open an issue explaining the problem and the observable expected behavior, then submit a focused PR with tests. Use Python 3.10+ and standard-library dependencies where practical. Run the README test, compile and release-gate commands. Keep implemented, experimental and roadmap claims separate.

Never contribute secrets, private project documents, model outputs containing personal data, copyrighted assets without permission or production configuration. Include dependency license details before adding one. Contributions intentionally submitted for inclusion are under Apache-2.0. No provider call should occur in CI. Useful starter work is listed in docs/ROADMAP.md.

Use a GitHub noreply commit email. The release gate also checks commit author and committer metadata to prevent accidental personal email publication.
